# 一剑击俱乐部工作台

面向击剑俱乐部的训练、比赛与成长记录评估产品，包含：

- 训练总览、训练计划与打卡
- 比赛成绩录入与核验
- 成长月报、问答社区与站内消息
- 注册、登录、密码重置与退出登录
- 首次身份选择、训练偏好设置和三步新手导览
- 桌面端与移动端响应式布局

## 运行

```bash
npm install
npm run dev
```

开发预览位于 `http://localhost:3000`。

```bash
npm run check
npm run build
```

## 评估数据说明

当前版本为前端评估体验。账户、登录状态、训练记录和引导进度仅保存在当前浏览器的 `localStorage` / `sessionStorage` 中，不会跨设备同步；清除浏览器数据会移除这些内容。页面中的人物、训练和比赛均为合成样本，请勿录入真实健康或敏感信息。
